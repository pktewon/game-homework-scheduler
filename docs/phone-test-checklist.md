## 2. 설치와 준비

1. APK를 설치하고 실행한다. 기존 앱이 있으면 업데이트로 설치한다. 앱 삭제·데이터 삭제는 개인 기록도 삭제하므로 보존 테스트에서는 사용하지 않는다.
2. 홈에서 공식 일정 새로고침을 누른다. 엔필 기존 프로필을 사용하고 명조·소전2를 등록한다. 명조·소전2의 일정은 현재 직접 등록 대상이다.
3. 실제 게임별 초기화 시각을 설정하고, 각 게임에 `[테스트]-회차ID-숙제A`, `숙제B`를 등록한다. A만 체크하고 B는 미완료로 둔다.
4. 별도 개인 게임 `[테스트]-회차ID`를 UTC+9로 등록한다. 이후 임시 이벤트·5분 초기화는 이 프로필에서 진행한다.
5. 필수 항목을 먼저 실행하고, 예약 알림 대기 중에 게임 실행·일일 초기화 검증을 진행한다. 각 예약 시험을 새로 만들 때 기준 시각을 다시 기록한다.

## 4. 참여·교환 마감 알림

이벤트 날짜·시각은 **한국 시각**으로 입력한다. 자정을 넘으면 다음 날짜도 지정한다. 제목에는 회차 ID를 넣어 다른 실제 일정의 알림과 구분한다.

알림 설정은 **모든 게임에 공통**이다. 홈 → **마감 알림 설정**에서 권한과 참여·교환 채널 허용을 확인하고 설정을 저장한다. 백그라운드 시험은 홈 버튼으로 나가 화면을 잠그며 휴대폰 설정의 강제 중지를 사용하지 않는다.

### A. 즉시 표시와 중복 방지

참여·교환 알림을 모두 **60분 전**으로 저장한 뒤, 별도 테스트 게임의 이벤트 → **이벤트 등록**에서 다음 새 이벤트를 만든다.

| 설정 | 값 |
| --- | --- |
| 제목 | [테스트]-회차ID-즉시 |
| 참여 시작 / 종료 | 현재보다 10분 전 / 30분 후 |
| 별도의 보상 교환 기간 사용 | 켬 |
| 교환 시작 / 종료 | 현재보다 10분 전 / 45분 후 |
| 완료 체크 | 참여·교환 모두 미완료 |

두 일정 모두 알림 기준 시각을 지났으므로 저장 후 표시를 확인한다. N05까지는 제목·기간·체크를 바꾸지 않는다.

### C. 확인 필요·완료 제외와 참여/교환 독립성

확인 필요 시험은 새 이벤트 `[테스트]-회차ID-미정`의 참여 시작을 10분 전, 종료를 **미정**으로 두고 교환 기간은 사용하지 않는다.

완료 제외 시험은 **전체 알림을 끈 뒤** 새 이벤트 `[테스트]-회차ID-참여완료`를 만든다. 참여 시작·종료는 10분 전·30분 후, 교환 시작·종료는 10분 전·45분 후로 둔다. 참여 카드의 체크 항목을 모두 체크하고 교환은 미완료로 유지한다. 이후 참여·교환 알림 60분 전, 전체 알림 켬으로 저장한다.

## 5. 일일 초기화와 이전 기록 보존

실제 게임 초기화 설정과 구분해 **별도 테스트 프로필(UTC+9)**의 **숙제 · 기록**에서 진행한다. 휴대폰 시각·시간대를 바꾸지 않는다.

1. 초기화 시각을 현재 한국 시각보다 **5분 뒤**로 지정한다. 예: 21:00에 준비하면 21:05. 자정 근처라면 다음 날짜 경계를 포함해 기록한다.
2. 숙제 `[테스트]-회차ID-초기화A`, `초기화B`를 새로 등록하고 A만 체크한다.
3. 현재 회차 시작·종료와 A 완료 시각을 기록한다. 초기화 시각까지 숙제 화면에서 기다린 뒤 홈에도 복귀해 요약을 확인한다.
4. 새 회차의 A를 체크하고 기록을 확인한 뒤 현재 A 체크를 해제한다. 이전 회차 A는 남아 있어야 한다.
