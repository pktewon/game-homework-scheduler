## 기능 범위

**기말 필수 구현:** 게임 관리, 이벤트 등록·수정, 종료 임박 조회, 참여·보상 체크, 일일 숙제 회차별 기록, 개인 메모, 로컬 데이터 보존, 모바일 게임 바로가기와 PC 플레이 안내.

**기본 기능 이후 확장:** 검수한 일정 JSON 수신, 중복 없는 병합, 갱신 상태 표시, 대표 게임 한 개의 공지 추출 검증.

**후속 확장:** 세 게임 전체 수집 서버, AI 추출 운영, 사용자 간 커뮤니티, 로그인·기기 간 동기화, PC 원격 실행.

## 기말 기능 점검표

| 상황 | 기대 결과 |
| --- | --- |
| 게임이 여러 개이고 종료일이 다른 이벤트가 있음 | 게임에 상관없이 마감이 가까운 미완료 이벤트부터 표시 |
| 임무는 끝났지만 보상을 수령하지 않음 | 보상 항목이 미완료로 남아 홈에서 확인 가능 |
| 참여와 교환의 마감이 다름 | 두 일정을 개별 관리하고 관련 일정으로 연결 |
| 종료 시각이 불명확함 | 기간 확인 필요 표시, 확정된 카운트다운과 분리 |
| 종료가 시작보다 빠르거나 필수 값이 없음 | 저장 전 오류 안내 |
| 초기화 직전·직후에 숙제를 체크함 | 각각 올바른 회차에 기록, 과거 기록 유지 |
| 앱을 종료했다가 다시 실행함 | 일정·체크·메모와 완료 기록 유지 |
| 연결 게임이 다른 이벤트를 메모에 지정함 | 저장 전 연결 오류 검사 |
| 게임이 휴대폰에 설치되지 않음 | 실행 불가 안내, 앱 오류 방지 |
| PC에서 플레이함 | Android 앱에서 수동 체크로 기록 가능 |
| 같은 JSON을 다시 받음 | 확장 구현 시 중복 이벤트 생성 방지 |
| 갱신 실패 또는 공지 날짜 변경 | 확장 구현 시 기록 보존과 확인 필요 상태 표시 |

위 기능 점검은 구현 단계에서 수행할 계획이며 현재 앱 테스트가 완료되었다는 의미는 아니다.
