# 기말 시연 대본 · 3~5분

앱 0.8.0 기준이다. 이 문서는 실제 발표·녹화에 사용할 순서와 대사이며 녹화 영상 자체는 아니다.

## 시연 준비

- APK를 설치하고 사용할 게임을 연결한다. 명조·소전2·엔필 중 설치된 게임 한 개로 실행을 시연한다.
- 시연용 개인 게임·숙제 2개와 참여/교환 기간이 다른 이벤트를 준비한다. 예시 이름 앞에는 [시연]을 붙인다.
- 홈 종료 임박은 확정된 진행 중·미완료·24시간 이내 일정을 사용한다. 참여와 교환 기간을 서로 다르게 입력한다.
- 초기화 경계는 별도 테스트 게임 UTC+9의 초기화 시각을 몇 분 뒤로 설정한다. 서버의 실제 초기화 시각이라고 설명하지 않는다.
- 알림을 시연한다면 전체·종류별 권한을 확인하고 기존 설정을 기록한다. 사전 알림을 60분으로 지정한 뒤 시작 10분 전·종료 30분 후인 새 예시 일정을 등록한다. 같은 마감은 한 번만 알리므로 새 시연 이벤트를 사용한다.
- 종료 후 테스트 숙제는 사용 중지하고 이벤트는 완료 처리하며 알림 설정을 복원한다.

## 발표 흐름

| 시간 | 화면·조작 | 설명 예시 |
| --- | --- | --- |
| 0:00~0:30 | 홈 | “여러 게임의 일일 퀘스트를 하다가 별도 이벤트 종료나 보상 교환을 놓치는 문제에서 시작했습니다.” |
| 0:30~1:10 | 종료 임박·오늘 숙제·상태 필터 | “마감이 가까운 미완료 일정부터 보고 게임별 현재 회차의 숙제를 확인합니다. 기간이 불명확하면 확인 필요로 남깁니다.” |
| 1:10~1:50 | 이벤트 상세·참여 항목 하나 체크 | “참여와 보상 교환은 별도 기간과 체크로 관리합니다. 참여를 체크해도 교환 완료는 바뀌지 않습니다.” |
| 1:50~2:20 | 게임 실행·스케줄러 복귀 | “연결한 설치 앱으로 이동합니다. 실행만으로 숙제 완료가 되지는 않고 직접 체크합니다.” |
| 2:20~3:10 | 숙제·이전 완료 기록 | “게임별 초기화 설정으로 회차를 나눕니다. 새 회차가 생겨도 이전 기록은 삭제하지 않습니다.” |
| 3:10~3:40 | 이벤트 연결 메모 | “게임별 개인 메모를 남기고 특정 참여·교환 일정에 연결할 수 있습니다.” |
| 3:40~4:20 | 알림 설정·도착 알림·상세 이동 | “참여와 교환 마감을 따로 설정합니다. 확인 필요·완료 일정은 제외하고 같은 마감은 한 번만 알립니다.” |
| 4:20~5:00 | 새로고침·저장된 체크·GitHub | “검수 JSON으로 공식 일정만 갱신하며 개인 기록은 유지합니다. Android 105개·수집기 27개 검사 결과와 사용자 휴대폰 확인 30개를 구분해 기록했습니다.” |

초기화·예약 알림 대기는 영상에서 생략하거나 미리 실제 녹화한 장면을 이어서 보여줄 수 있다. 아직 촬영하지 않은 영상을 촬영 완료로 표시하지 않는다. 알림은 기기 절전 상태에 따라 지연될 수 있으므로 실시간 시연에서는 여유 있게 준비한다.

## 예상 질문

| 질문 | 답변 핵심 |
| --- | --- |
| 게임 안의 완료를 자동으로 읽는가? | 완료는 사용자가 체크한다. 게임 실행이나 공식 일정 수신으로 완료 처리하지 않는다. |
| 세 게임 일정이 전부 자동인가? | 엔필 특정 공지의 수집·검수·JSON 배포와 앱 수신을 구현했다. 명조·소전2는 직접 등록하며 수집기는 후속 확장이다. |
| 갱신하면 체크가 사라지지 않는가? | 공식 정의와 개인 완료를 별도 테이블·고정 ID로 분리하고 갱신은 개인 기록을 변경하지 않는다. |
| 초기화 때 기록을 지우는가? | 회차 시작 시각을 키에 포함해 새 회차를 조회한다. 이전 완료는 남긴다. |
| 실제 휴대폰도 검증했는가? | 사용자가 기본 26개와 추가 4개를 정상으로 확인했다. 기종·시각·캡처 미제공 항목은 그대로 명시했다. |
| 혼자 구현할 수 있는 범위인가? | 개인용 로컬 저장과 검수 JSON 수신에 집중하고 서버 계정·커뮤니티·자동 완료 등은 후속으로 분리했다. |
