# 게임 숙제 스케줄러 · 최종 결과 보고서

정리일: 2026-10-24 · 앱 0.8.0 (versionCode 8) · Room 스키마 7 · 1인 Android 프로젝트

## 문제인식과 해결 결과

여러 게임의 일일 퀘스트를 하면서도 참여 기간과 보상 교환 기간이 서로 다른 이벤트 마감을 놓칠 수 있다는 경험에서 출발했다. 흩어진 종료 시각과 사용자의 완료 상태를 한 화면에서 확인하도록 설계했다.

홈은 24시간 이내 마감되는 미완료 일정을 먼저 보여주고, 게임별 현재 회차의 숙제 완료를 요약한다. 일정은 검수 JSON에서 가져오거나 직접 등록하며 참여·보상은 사용자가 체크한다. 게임을 실행한 사실을 완료로 처리하지 않는다.

## 현재 제약과 후속 확장

엔필 수집기는 특정 공지의 텍스트 구간을 처리한다. 새 공지 목록 자동 탐색·예약 수집, 명조·소전2 수집기, 앱의 배경 공지 갱신은 후속 범위다. 명조·소전2 일정은 직접 등록한다.

공식 일정의 개인 수정·자유 체크 항목 편집, 계정 로그인·기기 간 동기화·백업, 사용자 간 커뮤니티·PC 원격 실행·인게임 자동 완료 판정은 제공하지 않는다. 초기 기획의 세부 편집 목표와 차이를 남기며 핵심 제출 범위는 수동 일정 관리·검수 JSON 수신·기록 보존으로 마무리했다.

알림은 Android 절전 정책으로 지연될 수 있다. 기기를 바꾸거나 앱 데이터를 삭제하면 이 기기의 개인 기록은 복원되지 않는다. 추가 제조사·화면 크기·절전 환경 검증은 확장 과제다.
